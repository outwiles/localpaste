    Connecting another device

    1. Make sure the other device is on the same Wi-Fi or LAN as this computer — not a guest network, which usually keeps devices apart.
    2. On the other device, open the Network URL shown above in any browser, or tap "Show QR code for this device" and scan it with a phone camera.
    3. Devices connected to the same network can open the Network URL in their browser and use LocalPaste directly — nothing to install.
    4. To keep a specific paste reachable from other devices, set its visibility to LAN accessible when creating it.

    What LAN sharing actually does

    When a paste is set to LAN accessible and this server is reachable from other devices, anyone who can reach this computer on the network — and who has or guesses the paste's URL — can view that paste. Outwiles LocalPaste does not currently implement authentication or encryption for LAN access. Treat LAN sharing as convenient, not confidential: don't share anything on an untrusted network that you wouldn't hand to anyone else connected to it.
